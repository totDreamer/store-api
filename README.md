# Store Backend

Учебный backend-проект интернет-магазина на Python.

Проект создаётся постепенно в процессе изучения backend-разработки: от простой доменной модели на чистом Python до полноценного REST API с базой данных, тестами и контейнеризацией.

## Цели проекта

Основная цель — практическое изучение Python backend-разработки на одном развивающемся проекте вместо набора изолированных учебных задач.

В процессе разработки планируется изучить и применить:

* объектно-ориентированное программирование;
* обработку исключений;
* аннотации типов;
* структуру Python-проектов;
* PostgreSQL и SQL;
* SQLAlchemy;
* FastAPI;
* Pydantic;
* Alembic и миграции базы данных;
* pytest;
* асинхронное программирование;
* аутентификацию и авторизацию;
* Docker;
* развёртывание приложения.

## Текущее состояние

На текущем этапе реализована базовая доменная модель интернет-магазина на чистом Python без сторонних зависимостей.

### Product

Товар содержит:

* идентификатор;
* название;
* цену.

Реализована валидация входных данных.

Товары сравниваются по идентификатору и могут использоваться в качестве ключей словаря.

### User

Пользователь содержит:

* идентификатор;
* имя;
* email.

Реализована базовая валидация входных данных.

### Order

Заказ связан с пользователем и содержит товары с указанием их количества.

Реализованы:

* добавление товаров;
* объединение одинаковых товаров;
* автоматический расчёт общей стоимости;
* статусы `new`, `paid` и `cancelled`;
* оплата заказа;
* отмена заказа;
* запрет изменения оплаченного или отменённого заказа;
* пользовательские исключения для нарушения бизнес-правил.
