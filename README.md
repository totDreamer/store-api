# Store API

Учебный backend-проект интернет-магазина на Python.

Проект развивается постепенно в процессе изучения backend-разработки: от простой доменной модели на чистом Python до полноценного REST API с базой данных, тестами и контейнеризацией.

## Цели проекта

Основная цель — практическое изучение Python backend-разработки на одном развивающемся проекте вместо набора изолированных учебных задач.

В процессе разработки планируется изучить и применить:

* объектно-ориентированное программирование;
* обработку исключений;
* аннотации типов;
* структуру Python-проектов и пакетов;
* PostgreSQL и SQL;
* SQLAlchemy;
* FastAPI;
* Pydantic;
* Alembic и миграции базы данных;
* pytest;
* асинхронное программирование;
* аутентификацию и авторизацию;
* Docker;
* развёртывание приложения.

## Текущее состояние

На текущем этапе реализована доменная модель интернет-магазина на чистом Python без сторонних зависимостей.

Код разделён на пакет `store`, содержащий модели и доменные исключения. `main.py` используется как точка входа и для демонстрации работы модели.

### Product

Товар содержит:

* идентификатор;
* название;
* цену.

Реализованы:

* валидация входных данных;
* нормализация цены к `float`;
* сравнение товаров по идентификатору;
* поддержка использования `Product` в качестве ключа словаря через `__eq__` и `__hash__`.

### User

Пользователь содержит:

* идентификатор;
* имя;
* email.

Для входных данных выполняются базовая валидация и нормализация строковых значений.

### Order

Заказ связан с пользователем и содержит товары с указанием их количества.

Реализованы:

* добавление товаров;
* объединение товаров с одинаковым идентификатором;
* автоматический расчёт общей стоимости;
* статусы `new`, `paid` и `cancelled`;
* оплата заказа;
* отмена заказа;
* запрет изменения оплаченного или отменённого заказа;
* инкапсуляция внутреннего состояния заказа.

## Обработка ошибок

Доменные исключения наследуются от общего `StoreError`.

Текущая иерархия:

```text
StoreError
├── ValidationError
└── OrderOperationError
    └── InvalidOrderStatus
```

`ValidationError` используется для некорректных данных, переданных доменным моделям.

`OrderOperationError` объединяет ошибки недопустимых операций с заказом, а `InvalidOrderStatus` используется при попытке выполнить операцию, несовместимую с текущим статусом заказа.

## Структура проекта

```text
store-api/
├── store/
│   ├── __init__.py
│   ├── exceptions.py
│   └── models.py
├── .gitignore
├── LICENSE
├── README.md
└── main.py
```

* `store/models.py` — доменные модели `Product`, `User` и `Order`;
* `store/exceptions.py` — иерархия исключений проекта;
* `store/__init__.py` — инициализация Python-пакета;
* `main.py` — точка входа и демонстрация работы доменной модели.
